# excel-sales-operations-analytics
Excel Sales Operations Analytics project featuring data cleaning, lookups, conditional aggregation, pivot tables, and advanced Excel analysis on a retail sales dataset.

Project Objective

The objective of this project was to use Excel to solve real-world sales analytics problems involving:

Data lookup and retrieval
Data cleaning and quality diagnostics
Conditional aggregation
Pivot table analysis
Advanced Excel functions
Sales representative performance analysis
Revenue and profitability analysis
📁 Dataset

The workbook contains multiple interconnected datasets:

Orders – 2,000 sales orders
Customers – customer information
Products – product and pricing information
Sales_Reps – sales representative details
Targets – monthly sales targets
Q1_Lookups – lookup-function questions
Q2_Cleaning – data cleaning and quality analysis
Q3_Aggregation – conditional aggregation analysis
Q4_Pivot – pivot table analysis
Q5_Advanced – advanced Excel analysis
Workings – supporting calculations
